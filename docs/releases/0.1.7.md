# Heel 0.1.7 — Screenshot chat and readable panels

- Drag or paste a screenshot into chat, or use **Attach screenshot or photo**. Review/remove the preview, then Send to ask your selected AI about it. Codex uses your existing ChatGPT subscription; no API key is needed.
- The macOS file picker keeps the composer open while you choose a file. Failed image messages retain their screenshot for an explicit retry during the current session.
- The composer reserves its own space. Settings, replies and other panels show one active reading surface, with Back restoring the previous panel.
- Update progress, errors and Restart appear in a compact status row. Notices have their own bounded row and a dismiss button, so they do not cover navigation.

**Updating:** Heel 0.1.5 and later download the update automatically and offer **Restart to update**. To check now, open Settings → About → Check for updates. Earlier versions need the DMG once. Apple silicon Mac required.

**Image privacy and limits:** one image per message, up to 20 MB, normalized to a 2048-pixel working copy. Import/drop/paste alone sends nothing to the AI. Original files stay untouched. Image bytes are not stored in conversation history; reattach the image after quitting or for a later exchange that needs its pixels.

**Validation:** 812 tests and typechecks; browser screenshot drop/paste/picker, retry, restart privacy and small-window layout checks; native picker, live subscription vision and Settings/Reply navigation. Native Finder-to-window physical drag, OS bitmap paste, Iris’s Mac and VoiceOver were not directly tested.
