Heel 0.1.3 adds job application preparation, review and approved submission.

## For Iris
1. Install the DMG below by dragging Heel into Applications, replacing the older version after quitting it.
2. Open **Job applications** on Today, or ask Heel to prepare an application with the job URL.
3. Supply your facts/CV. Let Heel fill the form, correct the suggested answers, then review each outgoing site request. **Allow once** sends only that request. The final application stays held until approval.
4. Look for the site's confirmation in Heel. If the result is uncertain, check the destination before trying again; Heel does not automatically resubmit.

Heel can use standard form controls and screenshot assistance for unfamiliar/custom pages. It uses a separate browser profile. Complete sign-in or human verification yourself in its browser. Facts/page content and, when needed, screenshots go to your selected AI; approved requests and attached documents go to the displayed site.

## Requirements
- Apple silicon Mac; Node 22 or newer.
- Chrome, Brave or Edge installed.
- An AI configured in Settings. Screenshot assistance requires a vision-capable model; live testing used Codex.
- PDF, DOC, DOCX or TXT attachments up to 5 MB each. PDF text extraction currently needs Apple's command line tools; you can attach the PDF and paste facts instead.
