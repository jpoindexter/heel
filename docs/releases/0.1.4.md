Heel 0.1.4 removes the Apple command-line-tools requirement for reading CV PDFs.

The PDF reader is now bundled and signed inside Heel. Select your CV and press **Use … as facts**. Text PDFs are read directly; image-only pages use macOS's built-in Vision OCR. Mixed text/scan PDFs are supported. Extraction runs locally and needs no AI account, Python installation, EasyOCR package or extra model download.

## Verified
- Native app: imported both text and scanned PDFs through the macOS file picker with developer-tool lookup disabled, preserving an unsaved applicant note.
- Recognized synthetic English text, an email and French accents. No AI was configured for this test and no outgoing site request was approved.
- Tests cover mixed PDFs, locked/blank documents, the 50-page limit and preserving existing facts after extraction failure.
- 792 tests across 154 files passed, plus typecheck and staged secret scan.

## Install
Quit the older Heel, drag Heel from the DMG into Applications and replace the old app. Your existing data stays in its current folder. Apple silicon Mac, Node 22+, and the same application-browser/AI setup as 0.1.3 are required for job applications. PDF extraction itself needs no developer tools or AI.

Review OCR text for mistakes. PDFs must be unlocked and have at most 50 pages; attachments are limited to 5 MB and facts to 20,000 characters. Reading is bounded to 45 seconds; a first OCR run can be slower, and difficult documents may need pasted facts. Iris's own CV and other Macs remain unverified. This patch does not establish compatibility with every job site.
