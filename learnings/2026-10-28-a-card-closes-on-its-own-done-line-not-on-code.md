# A card closes on its own Done line, not on the code that serves it

Five art cards looked finished: every clip they asked for was in the puppy pack and wired through
one table. Their descriptions had been overwritten by a pasted status, but the original scope was still
there under a "Historical card context" tail, and each original ended with a Done line that named a
look in the real app ("do not call it smooth from frame count alone", "no stripes while moving").

Rule: before moving a card, read to the end of its description and find the Done line. If it names an
observation only a person can make, the card goes to Blocked / needs Jason with a note that says what
the code did and the one sitting that would close it, not to Done. Code coverage of the scope is a
status update, not a close.

Also: a Trello description that opens with a pasted update usually keeps the original below a divider;
read the tail before saying the scope is lost.
